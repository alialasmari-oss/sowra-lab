    push.js         الإشعارات

## القواعد الثلاث

**١. الاستيراد باتجاه واحد**
`main → features/ → core/`
`core/` لا يستورد من `features/` أبداً — وإلا دورة مغلقة.

**٢. الحالة بمكان واحد**
أي متغير يُكتب من أكثر من ملف يوضع في `core/state.js`.
**لا تعرّف `let x` تُكتب من ملف آخر** — مستحيل بالوحدات.

**٣. الميزة تنادي ميزة عبر الحاجز**
```javascript
import { need } from '../core/hub.js';
const openSheet = need('openSheet');   // دالة
const PHOTO_TAGS = () => get('PHOTO_TAGS');  // قيمة
```

## الفحص

```bash
node check.mjs
```
يفحص: التكرار · الدورات · الأنماط الخاطئة · `onclick` المفقودة · الأحجام.
**شغّله بعد كل تعديل.**

## الجسر — مؤقت

`main.js` ينشر الدوال على `window` حتى تعمل `onclick` بالـHTML.
**الهدف إفراغه:** كل ما نقلت `onclick` لمستمع أحداث، تُحذف من الجسر تلقائياً.

## ما لم يُختبر

- **المتصفح الحقيقي** — الاختبار كان بـjsdom (يكشف المنطق لا العرض)
- الكاميرا والتسجيل والموسيقى
- اللمس والتمرير على الجوال
- الإشعارات الفعلية
