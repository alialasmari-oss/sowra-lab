## عن المنصة

أينما توجهت في مناطق المملكة، ستجد عدسات أهلها ترشدك — إلى منتزه بعيد، أو موقع يصعب الوصول إليه، أو شبر جميل ما كنت لتعرفه لولا صورهم.

نؤمن أن أصدق صورة للمكان يلتقطها ابن المكان. فبنينا ساحة يرفع فيها المصورون لقطاتهم من كل منطقة وقرية ومعلم، والجمهور يقيّم ويصوّت، والأجمل يتصدر.

**شعارنا:** من قريتك… إلى العالم 🇸🇦

## ما يميّزها

## الهوية البصرية

ألواننا ونقوشنا مستوحاة من فن **القطّ العسيري** — الفن السعودي المسجل في قائمة اليونسكو للتراث الثقافي غير المادي — احتفاءً بإبداع نساء الجنوب اللواتي حوّلن الجدران إلى لوحات.

---

## التقنية

تطبيق ويب تقدّمي (PWA) يعمل على كل الأجهزة بلا تثبيت، ويمكن إضافته للشاشة الرئيسية ليعمل كتطبيق أصلي.

- **الواجهة:** HTML · CSS · JavaScript — بلا أطر عمل
- **الخلفية:** Supabase (قاعدة بيانات وتخزين ومصادقة)
- **الخرائط:** Leaflet + OpenStreetMap
- **الطقس:** Open-Meteo

**التثبيت على الجوال:**
- 🍎 **iPhone:** Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»
- 🤖 **Android:** Chrome ← القائمة ⋮ ← «تثبيت التطبيق»
